# ways + определительная часть без связующего слова

## Модель

`the ways + subject + predicate` = `the ways that/in which + subject + predicate`

## Значение

После `ways` может сразу следовать часть, описывающая эти способы. Необязательные `that` или `in which` при этом опускаются.

## Разбор исходного контекста

В `the ways servers can be inconsistent with each other` слова `servers can be inconsistent with each other` описывают `ways`: «способы, которыми серверы могут рассогласовываться друг с другом». Вся группа является вторым дополнением глагола `reduces` после `the degree of nondeterminism`.

## Полная или более простая форма

Полная версия: `the ways in which servers can be inconsistent with each other`. В естественном русском переводе подразумеваемое количество выражается явно: «количество способов, которыми серверы могут рассогласовываться».

## Ограничения и типичные ошибки

`And` соединяет два объекта `reduces`: степень недетерминированности и способы рассогласования. Оно не начинает отдельное предложение.
