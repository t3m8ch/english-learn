# in order to + инфинитив для выражения цели

## Модель

`in order to + base verb`

## Значение

Конструкция вводит цель действия и переводится как «чтобы», «для того чтобы» или «с целью».

## Разбор исходного контекста

В `in order to enhance understandability` конструкция `in order to` показывает цель, `enhance` стоит в начальной форме, а `understandability` является прямым дополнением: цель — повысить понятность.

## Полная или более простая форма

В большинстве утвердительных фраз `in order to` можно заменить простым `to` без существенного изменения смысла: `to enhance understandability`. Вариант с `in order to` длиннее, формальнее и явнее подчёркивает цель.

## Контексты

- `in order to enhance understandability`
  — Чтобы повысить понятность.
  — [Источник](../../phrases/2026/09/2026-09-16-001.md)

## Ограничения и типичные ошибки

После `in order to` используется начальная форма глагола: `in order to enhance`, не `in order to enhancing`. Конструкция не переводится по частям как «в порядке».
