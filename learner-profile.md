# Профиль учащегося

## Основной язык

Русский.

## Предпочтения объяснений

- Объяснять на русском языке.
- Для английских примеров давать естественный перевод.
- Сначала объяснять смысл всей фразы, затем детали.
- Показывать значение слова или выражения именно в исходном контексте.
- Не перегружать ответ уже понятными пользователю деталями.

## Известная лексика

Слова, которые пользователь явно отметил как понятные, не считать причиной непонимания конкретной фразы. Это не означает, что все их значения уже изучены.

## Наблюдаемые трудности

Этот раздел дополняется только устойчивыми наблюдениями по нескольким разобранным фразам. Единичную ошибку не считать устойчивой трудностью.
