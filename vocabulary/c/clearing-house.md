# clearing house

## Формы

Пишется раздельно (`clearing house`) или слитно (`clearinghouse`).

## Значение 1: центральный распределительный узел

### Когда используется

Буквально — расчётная палата, через которую проходят платежи между банками. В переносном смысле — центральная точка, через которую проходят запросы или информация и распределяются дальше, без их собственной обработки.

### Контексты

- `This program acts as a clearing house for requests to the POSTGRES system.`
  — Эта программа служит центральным распределительным узлом для запросов к системе POSTGRES.
  — [Источник](../../phrases/2026/09/2026-09-28-002.md)

### Примечание

Здесь метафора подчёркивает, что postmaster сам запросы не обрабатывает, а распределяет их по серверным процессам.
