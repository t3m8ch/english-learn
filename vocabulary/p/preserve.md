# preserve

## Значение 1: сохранить нетронутым, не дать уничтожить

### Когда используется

`Preserve X` означает оставить уже существующее в неизменном виде и уберечь от удаления или изменения. Модель `preserve X for Y` — «сохранить X, чтобы использовать для Y».

### Контексты

- `Preserve the FULL data directories of both nodes (orioledb_data checkpoint files -- *.xid dump / *.xidmap / control -- plus pg_wal) for post-mortem debugging.`
  — Сохраняем полные каталоги данных обоих узлов (файлы контрольных точек в `orioledb_data` и `pg_wal`), чтобы потом разобрать сбой.
  — [Источник](../../phrases/2026/09/2026-09-28-001.md)

### Примечание

`Preserve` не равно `save` в смысле «записать на диск»: файлы уже существуют, их просто не удаляют. Близкие слова — `keep`, `retain`; у `preserve` есть оттенок защиты от уничтожения, как в `preserve evidence` — «сохранить улики».
