# reset

## Формы

Неправильный глагол: `reset — reset — reset`. В исходной фразе — форма `resetting` после предлога.

## Значение 1: сбросить, вернуть в исходное состояние

### Когда используется

`Reset X` — вернуть систему, память или состояние к начальному виду, а не изменить настройки и не исправлять отдельные повреждения.

### Контексты

- `It also takes care of resetting the system if a backend crashes.`
  — Ещё он берёт на себя сброс системы, если какой-то серверный процесс упадёт.
  — [Источник](../../phrases/2026/09/2026-09-28-002.md)

### Примечание

`Reset` не значит «перенастроить»: для изменения настроек используется `reconfigure`.
