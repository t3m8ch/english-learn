# gate

## Формы

В исходной фразе — причастие `gated` в пассивном значении. Существительное `gate` — «ворота, шлагбаум».

## Значение 1: пропускать только при условии, ограничивать условием

### Когда используется

`Gate X` означает включать или разрешать X лишь при выполнении определённого условия. Модели: `X is gated by Y` — «X контролируется Y»; `gate X to Z only` — «ограничить X только случаями Z»; `gate X on Z` — «ставить X в зависимость от Z».

### Контексты

- `Gated by the caller to replica-TRAP catches only: the frequent SK-leak invariant trials must NOT trigger this or they would fill the disk.`
  — Вызывающий код включает это только тогда, когда TRAP сработал на реплике: частые прогоны проверки инварианта на утечку SK не должны это запускать, иначе они забьют диск.
  — [Источник](../../phrases/2026/09/2026-09-28-001.md)

### Примечание

Родственные выражения: `feature-gated` — «включается только флагом», `gated behind a config option` — «работает только при определённой настройке». Близкие по смыслу глаголы — `restrict to`, `limit to`, `guard by`.
